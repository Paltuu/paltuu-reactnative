# Project Rules

## Coral9 tickets
This repo is Coral9 project `paltuu-pk`. The connection is pinned to it, so you can omit `project` on every call. The `coral9` MCP server is connected and acts as the developer whose token it holds.
**No untracked work.** Every task that changes code, config, content or deliverables maps to a ticket, and the ticket reflects reality. Small changes are not an exception.
